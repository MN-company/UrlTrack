Workflow

Four steps,
one pipeline.

From link creation to visitor intelligence — in minutes.

1

Create a campaign

Set a slug, Safe URL, default source, and defenses. Generate a trackable link with optional QR code and UTM parameters.

2

Define the visitor flow

Use the visual node editor to decide what happens per visitor: redirect, gate, block, notify. Add conditions by device, country, bot score, or VPN risk.

3

Capture fingerprints

Every visitor fingerprinted via canvas, WebGL, audio, and network signals. The identity graph links them across devices and campaigns.

4

Review & act

Cross-tracking alerts flag matching identities. Review confidence, match reasons, and risk scores. Label, block, or escalate from the queue.
